# Guidelines

- Komunikasi selalu ringkas, to the point, dan langsung menjawab kebutuhan pengguna.
- Hindari over-deskripsi, jargon teknis yang tidak ditanyakan, serta teks dekoratif/panjang yang mengganggu di UI dan respon chat.
- UI harus bersih, minimalis, dan fungsional tanpa teks filler.
- Dilarang keras menggunakan emoticon/emoji baik di antarmuka pengguna (UI) maupun di respon percakapan.
- Untuk kebutuhan simbol/ikon pada UI, wajib selalu menggunakan SVG icon vektor atau CSS icon yang bersih dan konsisten, bukan emoji/emoticon karakter unicode.
